# Pinpoint

An AI overseer for agent traces that shows exactly where an agent went wrong,
and checks every citation against the trace before showing it. Runs on Muse
Spark Open.

This Space builds one pinned commit of
[github.com/ManasMehta1110/pinpoint](https://github.com/ManasMehta1110/pinpoint)
(see `PINPOINT_COMMIT` in the Dockerfile). Code, data, tests and every raw
model output are in that repository.
