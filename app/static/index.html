Pinpoint

Two citations: the offense, which must quote the agent's own action, and what contradicts it.

Paste any agent trace as JSON, or start from an example, and Pinpoint audits it live with Muse Spark Open. Citations that do not check out against the trace are never shown as findings.

The verifier decides whether a citation is real: the step exists, the quote is really there, and an offense quotes what the agent did, not what a tool returned. It uses only the trace, no answer key. Try to get a fake citation past it.
