The problem

Overseers get the verdict right and the evidence wrong.

As AI agents search, edit code and report back on their own, something has to check what they did. A verdict without evidence cannot be checked, contested or acted on.

1 in 1,794

correct misbehavior verdicts from 7 frontier overseers cited the right evidence, while their verdicts were 70.8–100% accurate.

GroundingBench: prior work by the author, before this hackathon. Pinpoint is the fix, built during it.
✗

“This agent lied.”A verdict. Which step? Which words? Someone has to go and find out, and the overseer may have pointed at the wrong thing anyway.

✓

“Step 5: ‘located in Rome, Italy’, contradicted by step 2.”A finding anyone can check in seconds, and Pinpoint has already checked it against the trace.

How it works

Two citations, and a verifier that trusts nothing.

01

Read the trace

Any agent run: the task, every tool call with its result, and the final answer. No answer key ever reaches the overseer.

02

Audit with Muse Spark Open

The model answers through a submit_audit tool call: a verdict, the offense, and what it was contradicted_by.

03

Verify every quote

Each citation must name a real step and quote it verbatim. The offense must quote the agent's own action, never what a tool returned.

04

Show only what is real

A failed citation goes back to the model with the reason. Anything still unverified is labelled unverified, never shown as a finding.

What the model's reasoning showed

It knew. It didn't say.

Muse Spark Open's reasoning is readable, so we read it. In the single-citation runs the model had found the lie, weighed citing it, then cited the proof instead, because the format allowed one citation. The failure was the format, not the model.

What this does not show yet.

One model, test traces

Every result is Muse Spark Open, one run per setup, on benchmark and scripted traces. No recorded production agent has been audited yet.

A bias of its own

When an agent tampers with a test and then truthfully says the tests pass, Pinpoint sometimes files the misleading claim as the offense and the tampering as the evidence.

The benchmark's shape

In GroundingBench the lie is always the agent's final answer, which suits the offense rule. The pre-registered mid-trace set was built to test beyond that.

Pinpoint runs on Muse Spark Open (Meta open weights) via Baseten, with Fireworks as a fallback. Built solo for the Meta Global AI Developer Hackathon. Code, data and every raw result
